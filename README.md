# Dev_Full_Stack-praTi-Codifica--2026
Este curso é uma iniciativa gratuita e prática, voltada para quem deseja ingressar na área de desenvolvimento web Full Stack. O projeto é uma parceria entre o Mais Para Ti (programa de formação profissional) e a Codifica (empresa especializada em educação em tecnologia), com o apoio de 40 empresas e parceiros do ecossistema de TI.
