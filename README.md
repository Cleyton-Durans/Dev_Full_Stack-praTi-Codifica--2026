## **📜 Sobre o Curso**

Este curso é uma **iniciativa social e educacional** que visa **formar desenvolvedores Full Stack Junior** para suprir a demanda do mercado de TI. É uma parceria entre a **+praTI** (movimento de empresários de TI do RS) e a **Codifica** (EdTech especializada em ensino de tecnologia).

### **🎯 Objetivo**
Proporcionar **formação de qualidade** em desenvolvimento Full Stack, preparando profissionais para **solução de problemas computacionais**, **desenvolvimento de aplicações modernas** e **inserção no mercado de trabalho**.

## **🏢 Sobre as Instituições**

### **🔹 Codifica**
- **O que é?** Uma **EdTech** especializada no ensino de **tecnologia, inovação e pensamento computacional** desde a educação básica até a profissional.

- **O que é?** Um **movimento social** criado em 2020 por empresários de TI do Rio Grande do Sul.
- **Missão:** Reduzir o **descompasso entre vagas disponíveis e profissionais qualificados** no mercado de TI, oferecendo **formação gratuita** para quem deseja ingressar na área.

### **📌 Detalhes dos Módulos**

#### **🔹 Módulo 1: Introdução à Ciência da Computação**
- **Tópicos:**
  - História da Computação
  - Introdução à Programação (JavaScript)
  - Estruturas de Controle (if, else, switch, for, while)
  - Estruturas de Dados (Arrays, Listas, Filas, Pilhas)
  - Funções e Objetos em JavaScript

#### **🔹 Módulo 2: Desenvolvimento Web - Frontend Essencial**
- **Tópicos:**
  - Git e GitHub
  - HTML5 (Semântica, Formulários, Tabelas)
  - CSS (Box Model, Flexbox, Grid, Responsividade)
  - JavaScript no Frontend (Manipulação de DOM, Consumo de APIs)

#### **🔹 Módulo 3: Desenvolvimento Web com React**
- **Tópicos:**
  - Introdução ao React
  - Componentes, Props e Estado
  - Ciclo de Vida (useEffect)
  - Gerenciamento de Estado (Context API)
  - Formulários e Eventos
  - Consumo de APIs RESTful
  - Roteamento (React Router)
  - Estilização (CSS Modules, Tailwind)
  - Hooks Personalizados
  - Testes de Componentes
  - **Projeto Final:** Desenvolvimento de uma SPA (Single Page Application)

#### **🔹 Módulo 4: Fundamentos de Java e Spring**
- **Tópicos:**
  - Sintaxe Básica de Java
  - Estruturas de Controle e Repetição
  - POO (Abstração, Encapsulamento, Herança, Polimorfismo)
  - Estruturas de Dados em Java
  - Introdução ao Spring Framework
  - Spring Boot (Componentes, Beans, Controllers, Services)
  - Tratamento de Exceções
  - Upload/Download de Arquivos
  - Testes Unitários e de Integração

#### **🔹 Módulo 5: Backend com Spring e Bancos de Dados**
- **Tópicos:**
  - Bancos de Dados Relacionais (MySQL/PostgreSQL)
  - Modelagem de Dados (Entidades, Relacionamentos)
  - SQL (DDL, DML, JOINs, Subconsultas)
  - Spring Boot (API RESTful, JPA, Hibernate)
  - Segurança (Spring Security, JWT, OAuth2)
  - **Projeto Final:** API RESTful Completa

#### **🔹 Módulo 6: DevOps e Inteligência Artificial com Python**
- **Tópicos:**
  - Introdução ao DevOps
  - Docker e Docker Compose
  - CI/CD com GitHub Actions
  - Python (Sintaxe, Estruturas de Dados, Funções)
  - Introdução à IA e Aprendizado de Máquina
  - Implementação de Modelos com Scikit-Learn
  - Consumo de APIs de IA

## **🎓 Projeto Final: Aplicação Web Completa**

### **📌 Objetivo**
Desenvolver uma **aplicação web completa** que atenda aos requisitos funcionais e técnicos abaixo.

### **🔧 Requisitos Funcionais**
1. **CRUD de Dados**
   - Implementar **Criação, Leitura, Atualização e Exclusão** de dados.
   - Interfaces **intuitivas e acessíveis**.
2. **Autenticação e Autorização**
   - Mecanismos **seguros** para login e controle de acesso.
   - Criptografia de senhas e sessões seguras.
3. **Controle de Versão**
   - Uso do **Git** para versionamento.
   - Repositório público no **GitHub** com histórico de commits consistente.

### **⚙️ Requisitos Técnicos (Não Funcionais)**
 | **Área** | **Requisitos** |
 |----------|----------------|
 | **Front-end** | ReactJS, responsividade, boa UX |
 | **Back-end** | Spring Boot, API RESTful, boas práticas |
 | **Banco de Dados** | MySQL ou PostgreSQL, tabelas normalizadas |
 | **Endpoints RESTful** | Tratamento de erros, documentação clara |
 | **Testes** | 70% de cobertura (JUnit para back-end, Jest para front-end) |
 | **Metodologias Ágeis** | Scrum ou Kanban, sprints bem definidas |

### **📂 Entrega do Projeto**
1. **Código-Fonte**
   - Repositório público no **GitHub**.
   - Histórico de commits **claro e organizado**.
   - Código **limpo, documentado e seguindo boas práticas**.
2. **Documentação Técnica**
   - Guia para **execução local**.
   - Descrição da **arquitetura** (front-end, back-end, banco de dados).
   - Detalhamento das **funcionalidades implementadas**.
   - **Aspectos relevantes** (desafios, soluções, decisões de design).
3. **Demonstração ao Vivo**
   - Apresentação das **funcionalidades implementadas**.
   - Explicação das **decisões de design e arquitetura**.
   - **Q&A** sobre o funcionamento e implementação.

## **❓ FAQ (Perguntas Frequentes)**

### **💬 O curso é gratuito?**
✅ **Sim!** É uma **bolsa de estudos** para a trilha de Dev Full Stack Jr. Ao final do curso, os alunos que se destacarem serão encaminhados para **entrevistas de emprego ou estágio** em empresas parceiras.

### **💻 São necessários conhecimentos prévios de programação?**
❌ **Não!** O curso parte do **zero**, com introdução à programação.

### **🕒 Não consigo assistir às aulas à noite, e agora?**
🎥 **Todas as aulas ficam gravadas** e podem ser acessadas assincronamente.

### **📜 O curso emite certificado?**
✅ **Sim!** Ao final do curso, os alunos aprovados nas atividades recebem **certificado de conclusão**.
