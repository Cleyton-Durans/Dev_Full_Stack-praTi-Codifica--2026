Falando sobre propriedades

Propriedades do flex box

    Propriedade flex-direction -> row, row-reverse, column, column-reverse
  • Propriedade flex-basis -> auto, flex-start, flex-end, center, space-between, space-around

  • Propriedade flex-wrap -> nowrap, wrap, wrap-reverse

  • Propriedade flex-flow -> flex-direction + flex-wrap

  • Propriedade justify-content -> flex-start, flex-end, center, space-between, space-around

  • Propriedade align-items -> stretch, flex-start, flex-end, center

  • Propriedade align-content -> stretch, flex-start, flex-end, center
